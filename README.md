# 🛒 Loja POO

Projeto de gerenciamento de **produtos e categorias**, desenvolvido com:

- **Back-End:** Node.js, TypeScript, Express e MySQL
- **Front-End:** HTML, CSS e JavaScript

---

# 📂 Estrutura do projeto

```txt
Loja_POO/
│
├── BACK-END/
│   ├── docs/
│   │   └── README.md
│   └── src/
│
└── FRONT-END/
    ├── docs/
    │   ├── README.md
    │   └── script.sql
    ├── css/
    |   └── styles.css   
    ├── index.html
    └── script.js
```
